# Nxtgen Business Management App — Demo

A self-contained, mobile-first HTML prototype inspired by the supplied mobile dashboard reference.

## Run locally
Open `index.html` in a modern browser. It does not require a build step or external libraries.

## Publish free with GitHub Pages
1. Create a **public** GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Open the generated GitHub Pages URL.

## Demo limitations
This is a front-end prototype. Records are kept in memory for the current page session; there is no secure authentication, server, database, or cloud synchronization. Do not enter real customer-sensitive data.
